# 러닝허브 (LearningHub)

교육 수요조사부터 과정 신청, 만족도 평가, 운영 분석까지 한 흐름으로 이어지는 **사내 교육 운영 웹앱**입니다.
현업에서 반복되던 운영 업무를 직접 도구로 만들어 본 포트폴리오 프로젝트입니다.

**▶ 체험하기:** https://hr404lab-learninghub.vercel.app

> 화면의 과정, 신청, 응답은 모두 예시 데이터입니다. 체험 모드에서 자유롭게 신청하고 응답해 볼 수 있으며, 새로고침하면 초기화됩니다.

## 왜 만들었나

교육 운영 데이터는 보통 따로 흩어져 있습니다.

- 수요조사는 설문 도구에
- 신청 접수는 메일이나 엑셀에
- 만족도 평가는 또 다른 설문에...

그래서 "수요가 있었던 주제를 실제로 개설했는가", "어떤 과정을 증설하거나 보완해야 하는가"를 판단하려면 매번 자료를 모아 손으로 대조해야 했습니다. 러닝허브는 이 네 단계를 하나의 데이터 흐름으로 연결합니다.

## 주요 기능

| 단계 | 기능 |
|---|---|
| 01 수요조사 | 부서·직급, 관심 주제(최대 3개), 선호 방식, 희망 시기 수집 |
| 02 교육신청 | 분야별 필터, 잔여석 표시, 정원 초과 시 대기 접수, 취소 시 대기자 자동 확정 |
| 03 만족도 평가 | 전반적 만족도, 현업 적용 가능성, 추천 의향(NPS) |
| 04 운영 대시보드 | KPI, 수요 대비 개설 현황, 과정별 운영표, 부서별 신청, 선호 교육 방식 |

### 의사결정을 돕는 자동 인사이트

대시보드는 데이터를 보여주는 데서 그치지 않고, 다음 행동을 제안합니다.

- **개설 검토**: 수요조사에서 많이 꼽혔지만 개설된 과정이 없는 주제
- **차수 증설**: 대기자가 많은 과정
- **내용 보완**: 현업 적용도가 낮게 나온 과정

## 설계 포인트

- **실제 운영 규칙 반영**: 정원 관리, 대기 순번, 취소 시 자동 승계 등 현업에서 손으로 처리하던 규칙을 기능으로 구현
- **평가 지표 설계**: 커크패트릭 모형의 반응(만족도)과 행동(현업 적용)을 분리해 측정하고, NPS로 추천 의향을 확인
- **모바일 우선**: 구성원이 휴대폰으로 바로 신청·응답할 수 있도록 설계, 다크 모드 지원

## 기술

- AI 코딩 도구(Claude)와 협업해 기획부터 구현까지 진행
